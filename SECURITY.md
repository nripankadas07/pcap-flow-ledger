# Security reporting

Do not post secrets, private captures or cookie values in public issues. Contact the maintainer through the profile's public contact channel to arrange private disclosure; public vulnerability reporting settings may be unavailable. Report commit, Python version, impact and a synthetic reproduction. This offline tool is not a security boundary or anonymizer. Operate only on files you are authorized to inspect. Unsupported inputs are rejected or explicitly counted; outputs can retain metadata. No telemetry, remote calls or automatic writes in the runtime tool.
